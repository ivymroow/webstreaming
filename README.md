## Railway environment

Set these in Railway variables before deploying:

- `NODE_ENV=production`
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `TMDB_KEY`
- `SESSION_SECRET`
- `CORS_ORIGINS`
