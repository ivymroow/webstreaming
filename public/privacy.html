privacy policy

last updated: september 4, 2026

web-streaming-addon adds a download panel on web-streaming.site for media streams detected in the current browser tab.

data collection

the extension does not collect, sell, transfer, or share personal information. it does not use analytics, ads, tracking pixels, or external telemetry.

local processing

video stream urls and page information are processed locally in the browser so the extension can show downloadable media options and start downloads requested by the user.

storage

the extension may store temporary settings or detected media information in chrome extension storage. this data stays on the user's device and is used only for download functionality.

remote code

the extension includes its javascript code inside the extension package. it does not load or execute remote code.

third parties

the extension does not send user data to the developer or to third-party servers. media urls may come from websites and embedded players opened by the user.

removing data

users can remove locally stored extension data by removing the extension from chrome or clearing extension site data in browser settings.
